# PicVocab

离线 Windows 图解背单词应用。以《DK 英语 10000 词》的 422 个场景为学习单位，提供背诵、默写与听力三种模式，学习进度、复习计划与单词笔记均保存在本机。

> 当前版本：0.1.0

## 下载与安装

- 系统要求：Windows 10 / 11 x64
- 快速下载：[**PicVocab 0.1.0**](https://github.com/Valerie-space/picvocab/releases/download/v0.1.0/PicVocab_0.1.0_x64-setup.exe)

## 使用文档

安装完成后的首次启动、功能操作、复习规则等见 [使用指南](docs/使用指南.md)。

## 数据与隐私

学习数据保存在本机，无需联网；卸载或覆盖安装不会删除学习进度。重置全部学习记录可在设置页执行，操作不可撤销。
