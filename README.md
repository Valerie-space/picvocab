# PicVocab

离线 Windows 图解背单词应用。以《DK 英语 10000 词》的 422 个场景为学习单位，提供背诵、默写与听力三种模式，学习进度、复习计划与单词笔记均保存在本机。

> 当前版本：0.1.0。安装包与校验和将在 Releases 提供。

## 下载与安装

系统要求：Windows 10 / 11 x64，Microsoft Edge WebView2 运行时；建议预留约 2 GB 磁盘空间。

> 安装包已包含 WebView2 运行时；系统缺少时安装程序会自动安装，无需另行下载，可能显示一次管理员授权。

1. 在 Releases 下载 `PicVocab_0.1.0_x64-setup.exe`。
2. 运行安装程序，按提示完成安装。
3. 从桌面或开始菜单启动 PicVocab。

## 使用文档

安装完成后的首次启动、功能操作、复习规则、笔记与词典用法见 [使用指南](docs/使用指南.md)。

## 数据与隐私

学习数据保存在本机，不联网、不收集数据；卸载或覆盖安装不会删除学习进度。重置全部学习记录可在设置页执行，操作不可撤销。
