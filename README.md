# PicVocab

离线 Windows 图解背单词应用。以《DK 英语 10000 词》的 422 个场景为学习单位，提供背诵、默写与听力三种模式，学习进度、复习计划与单词笔记均保存在本机。

> 当前版本：0.1.0。安装包与校验和将在 Releases 提供。

## 使用文档

安装完成后的首次启动、功能操作、复习规则、笔记与词典用法见 [使用指南](docs/使用指南.md)。

## 系统要求

- Windows 10 / 11 x64。
- Microsoft Edge WebView2 运行时（安装包已包含；Windows 11 通常已内置）。
- 建议预留约 2 GB 磁盘空间（安装包包含 WebView2 运行时）。

## 下载与安装

1. 在 Releases 下载最新 `PicVocab_<版本>_x64-setup.exe`。
2. 运行安装程序，按提示完成安装；安装按用户级进行，无需管理员权限；系统缺少 WebView2 时可能出现一次管理员授权提示。
3. 启动 PicVocab。

安装包已内置 WebView2 运行时；系统缺少时由安装程序自动安装，无需另行下载。安装包未使用商业代码签名证书，Windows 可能显示 SmartScreen 提示，选择「更多信息」→「仍要运行」即可继续。如需校验安装包完整性，请与 Release 中的 `SHA256SUMS.txt` 比对。

## 数据与隐私

学习数据保存在本机，不联网、不收集数据；卸载或覆盖安装不会删除学习进度。重置全部学习记录可在设置页执行，操作不可撤销。

## 词典

词典功能使用用户自备的 MDict `.mdx` 文件，应用不附带词典数据。选择词典后，在小节页中键点击单词可查询原版词条；导入方法、配套资源与格式要求见 [使用指南的词典导入说明](docs/使用指南.md#导入自定义词典)。
