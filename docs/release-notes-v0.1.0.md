# PicVocab 0.1.0

发布日期：2026-11-26

首个公开版本。

## 安装

1. 下载 `PicVocab_0.1.0_x64-setup.exe`。
2. 运行安装程序，按提示完成安装。
3. 从桌面或开始菜单启动 PicVocab。

系统要求：Windows 10 / 11 x64，Microsoft Edge WebView2 运行时；建议预留约 2 GB 磁盘空间。

安装包已包含 WebView2 运行时；系统缺少时安装程序会自动安装，无需另行下载，可能显示一次管理员授权。

## 主要功能

- 422 个场景、约 9,951 个词条，覆盖 14 章、180 个单元。
- 背诵、默写、听力三种学习模式。
- 基于正确率与复习级别的间隔复习，掌握度 5 级。
- 今日待复习、今日学习、最近学习与学习记录。
- 单词笔记、场景与词条搜索、MDict 词典。
- 中文 / English 界面切换。
- 完全离线运行，无账号、无遥测。

## 已知限制

- 个别小节暂不支持「播放整节」，单词音频仍可播放。
- 111.1、171.1 存在书内重复编号，保留原书编号以便对照。
- 安装包未使用商业代码签名证书，Windows 可能显示 SmartScreen 提示；请核对下方 SHA-256 后再运行。
