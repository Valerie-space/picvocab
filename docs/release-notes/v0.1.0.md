# PicVocab 0.1.0

发布日期：2026-11-26

首个公开版本。

## 安装

1. 下载 `PicVocab_0.1.0_x64-setup.exe`。
2. 运行安装程序，按提示完成安装。
3. 从桌面或开始菜单启动 PicVocab。

系统要求：Windows 10 / 11 x64

## Release 文件说明

Release 中提供三个文件：

- `PicVocab_0.1.0_x64-setup.exe`：安装包。普通用户只需下载并运行此文件。
- `SHA256SUMS.txt`：安装包与更新清单的校验值，用于确认下载文件完整。不需要安装，普通用户可以忽略。
- `latest.json`：应用内自动更新使用的版本清单。不需要手动下载或打开。

安装时只需下载 `.exe`。另外两个文件由应用或需要核对文件完整性的用户使用。
